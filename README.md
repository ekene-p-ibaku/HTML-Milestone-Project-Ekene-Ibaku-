# EkeneCraft — Explore Our Solar System Through Data

A responsive HTML webpage exploring our solar system through data, built as part of the Novara Cohort web development programme. Features semantic markup, multimedia elements, a data table, and a contact form.

## About the Project

This project is a capstone HTML assignment that brings together everything covered in the Novara Cohort HTML curriculum. The page is themed around planetary science and uses real solar system data to demonstrate a range of HTML elements and best practices.

## Pages & Sections

- **Hero** — Introduction to the site with a call-to-action and a Contact Us link
- **Video** — Autoplaying, muted, looping video alongside descriptive text
- **Planet Gallery** — A 3-column grid of planet images using `<figure>` and `<figcaption>`
- **Data Table** — Planetary facts (mass, diameter, density, gravity) with proper `scope` attributes
- **Contact Form** — Validated form with fieldsets, labels, a city dropdown, and character limits

## Built With

- HTML5
- Semantic elements (`<header>`, `<main>`, `<footer>`, `<section>`, `<figure>`, `<fieldset>`)
- No CSS frameworks or JavaScript — plain HTML only

## Key HTML Concepts Demonstrated

- Semantic document structure
- Multimedia: `<video>` with `autoplay`, `muted`, and `loop.`
- `<figure>` and `<figcaption>` for images with captions
- Accessible tables using `scope="col"` and `scope="row"`
- Forms with `<fieldset>`, `<legend>`, and associated `<label>` elements
- Fragment links (`#contact-section`) for in-page navigation
- Footer navigation using unordered lists
